# AGENTS.md — Terminal302

## Contexto general

Terminal302 es una aplicación web para digitalizar la gestión operativa de una terminal de buses.

Stack principal:

- Backend: Laravel API REST
- Base de datos: PostgreSQL
- Frontend: Vue 3
- Autenticación: Laravel Sanctum
- Contenedores: Docker / Docker Compose
- Futuro despliegue: AWS

Este archivo contiene el contexto general del proyecto. Las reglas y convenciones específicas se han movido a:

- [backend/AGENTS.md](backend/AGENTS.md)
- [frontend/AGENTS.md](frontend/AGENTS.md)

Mantener este documento como punto de entrada con el contexto global del proyecto.
